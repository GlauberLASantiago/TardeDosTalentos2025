# 🎤 Tarde de Talentos - Igreja Presbiteriana Filadélfia

O **Tarde de Talentos - Igreja Presbiteriana Filadélfia** é uma aplicação web desenvolvida para apresentar de forma clara, organizada e visualmente atraente a programação de um evento artístico e musical. A página reúne informações gerais do encontro e exibe a sequência das apresentações em uma lista dinâmica, com destaque para títulos, participantes e duração de cada momento.

A proposta é transformar a programação do evento em uma experiência digital agradável, facilitando a consulta por participantes, organizadores e público.

## ✨ Funcionalidades

- Exibição do nome e contexto do evento
- Apresentação dos detalhes principais:
  - data
  - local
  - duração total
  - apresentador
- Lista dinâmica da programação
- Exibição de:
  - número da apresentação
  - título
  - participantes
  - duração
- Cores alternadas para destacar os itens da programação
- Animações suaves de entrada ao rolar a página
- Rodapé com data de geração automática
- Interface responsiva e visualmente organizada

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

## 🎯 Objetivo do Projeto

O projeto foi criado para servir como uma programação digital de evento, tornando mais fácil a visualização da ordem das apresentações e dos participantes envolvidos. Em vez de um cronograma estático, a página oferece uma leitura mais agradável e dinâmica para contextos presenciais, divulgação interna ou consulta organizacional.

## 📚 Conteúdo da Página

A página apresenta:

- título do evento;
- nome da instituição;
- informações gerais do encontro;
- lista completa das apresentações;
- nome dos participantes de cada item;
- tempo previsto de cada participação.

## ▶️ Como usar

1. Abra o arquivo HTML em um navegador moderno.
2. Consulte os detalhes gerais do evento no topo da página.
3. Role a página para visualizar toda a programação.
4. Acompanhe os títulos, participantes e tempos de cada apresentação.
5. Utilize a página como apoio para organização, apresentação ou divulgação do evento.

## 🧩 Estrutura da Página

A interface está dividida em três partes principais:

### 1. Cabeçalho
Apresenta o nome do evento e a identificação da igreja.

### 2. Detalhes do evento
Mostra informações rápidas sobre:

- data
- local
- duração
- apresentador

### 3. Programação
Lista as apresentações em sequência, com identificação numérica, participantes e tempo estimado.

## 🎨 Interface

O projeto utiliza uma identidade visual com fundo escuro e cartões claros, criando contraste e legibilidade. Entre os elementos visuais estão:

- cards informativos;
- lista de programação com bordas coloridas;
- efeitos de hover;
- animações de entrada;
- tipografia clara e espaçamento confortável.

## 📱 Responsividade

A aplicação foi planejada para funcionar bem em:

- computadores
- tablets
- celulares

## 📁 Estrutura do Projeto

O projeto está concentrado em um único arquivo HTML com:

- **HTML**: estrutura da página
- **CSS**: identidade visual, animações e layout responsivo
- **JavaScript**: geração automática da programação, animações por scroll e data dinâmica no rodapé

## ✅ Possíveis usos

Este projeto pode ser utilizado como:

- programação digital de eventos;
- página informativa para apresentações artísticas;
- cronograma visual para encontros musicais;
- material de apoio para organização de atividades em igrejas, escolas ou festivais.
